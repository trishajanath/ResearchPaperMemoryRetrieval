============================================================
RQ4 -- END-TO-END EVALUATION
============================================================

## 1. Research Question

How does dynamic memory governance improve downstream task performance
and safety compared with static memory retrieval?

## 2. Hypotheses (pre-registered)

H1: SACR achieves higher held-out outcome-proxy agreement than semantic-only retrieval.
H2: SG-QMS achieves equal or higher held-out outcome-proxy agreement than unguided SACR
    (conservative rule: PASS only if statistically significantly better).
H3: SG-QMS reduces exposure to unfavorable historical memories vs unguided SACR.
H4: SG-QMS preserves the RQ2 state/context eligibility invariant during prediction.

## 3. Dataset

UCI Diabetes 130-US Hospitals, 101766 encounter records.
STATE_COLS: ['age', 'gender', 'race', 'number_outpatient', 'number_emergency', 'number_inpatient', 'number_diagnoses']
CONTEXT_COLS: ['admission_type_id', 'admission_source_id', 'time_in_hospital', 'medical_specialty', 'num_lab_procedures', 'num_procedures', 'num_medications']
EXPERIENCE_COLS: ['insulin', 'change', 'diabetesMed']

## 4. Patient-Level Split

Total unique patients: 71518
Memory-pool patients: 57214
Held-out patients: 14304
Memory-pool rows: 81394
Held-out rows: 20372

Memory-pool class distribution: {'NO': 43902, '>30': 28390, '<30': 9102}
Held-out class distribution: {'NO': 10962, '>30': 7155, '<30': 2255}
Split is unstratified (label-blind): a simple random split over unique
patient_nbr values, no use of readmitted to construct or balance it.
Evaluation queries actually used: 300 (pre-committed cap MAX_EVAL_QUERIES=300 for computational tractability; sampled deterministically with seed 42 from the 20372 held-out rows, sorted by memory_id for a fixed, auditable order).

## 5. Outcome Proxy

Feedback mapping (unchanged, preserved from preprocess.py): {'NO': 1.0, '>30': 0.0, '<30': -1.0}
`readmitted` is an OUTCOME-DERIVED EXPERIMENTAL PROXY, not a causal
treatment-effect label, clinical ground truth, or medically optimal
recommendation. The downstream task is: predict the held-out patient's
readmitted category from retrieved historical experiences. This is an
experimental prediction task, not a clinical decision-support validation.

## 6. Leakage Prevention

The held-out patients' encounter rows are excluded from the retrievable
memory pool for ALL THREE conditions via sacr.py's/baseline_rag.py's
existing, additive `excluded_memory_ids` parameter (applied while walking
the full similarity ranking, so the embeddings' positional alignment is
never disturbed -- a filtered/subset memory_bank was deliberately NOT used
for this, since embeddings are indexed by the full, unfiltered row order).
Held-out readmitted/feedback values are read only AFTER a prediction is
produced, purely for evaluation logging -- never for query construction,
memory selection, thresholds, governance, top-k, quality scores, or
condition choice.

## 7. Experimental Conditions

A) Semantic baseline: state-neutral semantic retrieval only (state_neutral_text,
   unchanged from RQ1) -- no STATE_COLS access, no eligibility gate.
B) SACR (no governance): frozen state (>=0.70) + context (>=0.90) eligibility,
   unchanged ranking weights; no OGMM, no quarantine exclusion, no quality filtering.
C) Full SG-QMS: SACR retrieval + RQ3's exact governance mechanism (imported, not
   reimplemented) -- quarantined memories excluded from subsequent SG-QMS queries.
All three conditions receive the same held-out queries, same order, same memory
pool, same TOP_K=5, same CANDIDATE_K=100 (where applicable), same seed,
same majority-vote prediction rule. The only difference is memory governance.

## 10. Downstream Prediction Task

y_hat(q) = mode{y_m1, ..., y_mk} over the readmitted categories of the top-k
retrieved memories. Ties broken by ascending lexicographic order of the tied
category strings (ASCII order: '<30' < '>30' < 'NO'), fixed before evaluation.
If 0 eligible memories are retrieved, the query is recorded UNCOVERED with no
fabricated prediction; it counts as incorrect only in the all-queries accuracy
variant, and coverage is reported separately.

## 11. Evaluation Protocol

For SG-QMS: retrieve -> predict -> observe the RETRIEVED memories' own (already
historical) feedback -> update governance -> next query. The held-out query's own
outcome never enters governance or retrieval at any point. Baseline and SACR use
the same query sequence but never update any exclusion state from what they observe.

## 12. Metrics

Outcome-proxy accuracy (covered and all-queries variants), macro-F1 with per-class
support, coverage, negative-memory exposure (aggregate and per-query rate),
governance-specific metrics (SG-QMS), and alignment safety violation counts (SACR, SG-QMS).

## 13. Statistical Tests

Predefined primary comparisons only: SACR vs baseline, SG-QMS vs SACR, SG-QMS vs
baseline. Accuracy: exact McNemar test (binomial test on discordant pairs).
Continuous per-query metrics (negative-memory fraction, mean state/context
alignment): Wilcoxon signed-rank test (no normality assumption). No other tests
were run or selectively reported.

## 21. Interpretation

SACR vs baseline accuracy: 0.4069 vs 0.4800 (NOT SUPPORTED on H1).
SG-QMS vs SACR accuracy: 0.4069 vs 0.4069 (INCONCLUSIVE on H2, conservative
significance-required rule -- SG-QMS is NOT required to beat SACR for this
experiment to be informative; a null result here is reported honestly, not
reframed.
SG-QMS negative exposure (0.1230) vs SACR's (0.1230): NOT SUPPORTED on H3.
Alignment invariant: PASS on H4 -- SG-QMS's downstream
prediction task never violated the frozen state/context eligibility gate.

IMPORTANT: this experiment evaluates an outcome-proxy prediction task using
historical hospital records. It does NOT establish clinical efficacy, treatment
effectiveness, causal relationships, patient-level medical recommendations,
real-world deployment safety, or superiority for clinical decision making. The
`readmitted` variable is an observational historical outcome proxy; this
evaluates the computational memory framework, not a validated clinical
decision-support system.

## 22. Limitations

- Outcome-proxy limitation carried over from RQ3: governance feedback is
  derived from historical outcome labels already attached to stored memory
  records, not independent repeated environmental observations. This experiment
  does not claim to demonstrate online learning from genuinely new real-world
  feedback; it evaluates whether outcome-derived historical evidence can be
  operationalized into memory governance and improve downstream
  retrieval/prediction behavior.
- Evaluation is capped at 300 deterministically-sampled held-out
  queries (of 20372 available) for computational
  tractability, decided before any result was observed.
- The majority-vote prediction rule is a simple, fixed, auditable choice; it is
  not claimed to be an optimal predictor.
- H2 uses a conservative, predeclared significance-required rule specifically
  because no statistically justified non-inferiority margin could be derived
  from the existing design; a NOT SUPPORTED verdict on H2 does not mean SG-QMS
  performed worse, only that superiority over SACR was not established here.
- SG-QMS quarantined 0 memories here: 1354 distinct
  memories were touched across 1374 retrievals (~1.01
  retrievals per memory on average). Unlike RQ3's deliberately-repeating 20-archetype
  cycle, RQ4's 300 evaluation queries are DISTINCT real
  held-out patients, so the same memory rarely recurs in enough top-k sets to reach
  N_MIN=3 retrievals within this evaluation's size. This is a direct
  consequence of query diversity at this sample size, not evidence that the quarantine
  mechanism is broken (RQ3 already verified it fires correctly under repeated exposure).

## 24. Conclusion

Under this deterministic, patient-level held-out protocol, SACR's frozen state/context
eligibility gate did not demonstrably improve downstream outcome-proxy agreement over semantic-only retrieval (H1).
SG-QMS governance was not shown to
significantly improve accuracy beyond unguided SACR (H2), while not reducing exposure to
unfavorable historical memories (H3) and fully preserving the RQ2 alignment invariant
(H4). These are narrow, mechanism-level findings on one outcome proxy, one
deterministic patient-level split, and one prediction rule -- not a claim of
clinical validity, causal effect, or real-world deployment readiness.
