RQ4-B -- CONTROLLED REPEATED-EXPOSURE RECURRENCE EXPERIMENT
==============================================================================

## 1. Research Question

Under forced, controlled repeated exposure of the SAME held-out queries, does SG-QMS's
governance mechanism (a) progressively reduce exposure to repeatedly-negative memories,
(b) change retrieval sets relative to SACR, (c) change downstream predictions, (d) change
downstream correctness, and (e) preserve SACR's state/context safety guarantees?

## 2. Why Recurrence-Controlled Evaluation Was Introduced

RQ4-final (results/rq4_final/, N=3,000, preserved unmodified) found OGMM mechanically
active (17 quarantines, 100% effectiveness, 0% false-quarantine) but with a per-query
effect size too small to detect: SACR and SG-QMS's retrieved sets differed for only 1-2
of 2,910 covered queries, and 0 predictions changed. This experiment isolates whether
that null downstream result was an exposure-volume artifact by forcing much higher
per-memory retrieval counts within a small, fixed, auditable query set.

## 3. How Recurrence Was Constructed

Q1..Q50: the first 50 rows of the SAME seed-42 full deterministic
permutation of the held-out set used by rq4_sequential.build_full_deterministic_sequence
(imported unmodified). This fixed set was repeated for 20 cycles, unmodified, in the
same order every cycle -- 1000 total evaluation rounds per condition. No query content,
state, context, experience field, or historical outcome was changed between cycles.

K_QUERIES=50 and CYCLES=20 were fixed before this experiment ran and were not adjusted after inspecting results.

## CRITICAL FEEDBACK CAVEAT

Each memory's feedback is a fixed historical attribute; repeated retrieval returns the identical historical value every time. This experiment is a controlled repeated-exposure simulation of already-recorded historical outcomes, not new independent environmental feedback.
Concretely: a memory's average_utility is exactly its fixed feedback value after any
number of retrievals (feedback never changes), so a memory with historical feedback=-1.0
becomes quarantine-eligible deterministically as soon as retrieval_count>=N_MIN=3 (i.e.
by the end of cycle 3) and is quarantined the next time it is checked. This is a
deterministic mechanical consequence of the frozen governance rule applied to a fixed
historical record -- not evidence of new clinical events or independent new evidence.

## 4. What Remained Frozen

SACR: state_threshold=0.7 context_threshold=0.9 lambda=(0.6,0.25,0.15) top_k=5 candidate_k=100

Feedback mapping: {'NO': 1.0, '>30': 0.0, '<30': -1.0}   Random seed: 42
Patient-level split: identical to RQ4 (experiments_rq4.build_split, unmodified, unchanged split_info).

## 5. Dataset and Patient-Level Split

Total unique patients: 71518   Memory-pool patients: 57214   Held-out patients: 14304

## 6. Exact Evaluation Protocol

Two conditions (SACR: no governance; SG-QMS: SACR + persistent OGMM state across ALL
20 cycles) process the IDENTICAL repeated query sequence, in the same order, from the
same initial memory bank. Each round is predicted, logged, THEN (SG-QMS only) governance
is updated from the retrieved memories' own historical feedback -- never from the current
query's own true label. Both conditions reuse experiments_rq4_sequential.run_sequential_condition
unmodified, checkpointed at every cycle boundary.

## 16. Limitations

- This is a controlled repeated-EXPOSURE simulation (see Critical Feedback Caveat), not a
  simulation of genuinely new, independent clinical events -- quarantine dynamics here are
  deterministic given each memory's fixed historical feedback sign.
- Only 50 held-out patients are used; results are a mechanism stress-test on this specific
  fixed subset, not a claim about the full held-out population (see RQ4-final for that).
- Per-cycle McNemar tests (n=50) are individually low-powered; the cycle-level test (n=20
  cycles) trades query-level detail for a valid, non-pseudo-replicated unit of analysis.
- SACR's own trajectory across cycles is unconstrained (no governance), so any oracle-style
  effectiveness/false-quarantine comparison inherits the same caveat documented in RQ3/RQ4-final.
- Single deterministic seed/order (42) and one fixed query subset; a different subset of 50
  patients could show different specific memories reaching quarantine, though the underlying
  deterministic mechanism (Critical Feedback Caveat) would apply identically.
